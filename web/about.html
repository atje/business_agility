The purpose of this simulation is to demonstrate how organization structure and setup impacts overall performance of the system.
Note - No information in this simulation is collected, everything is running solely in your local browser.

You start by configuring the organization through the Teams and handoffs section. You can add teams, define their internal work stages, and define how work is handed off between the teams. The Editor can be hidden to give more space to the simulation view during simulation.

You can configure the simulation parameters in the Parameters section. Hover over the parameter fields to see a description of what they mean. Once you have configured the organization and set simulation parameters, you can save and later reload configurations. It is possible to have multiple configurations saved in the browser, and you can switch between them at any time.

In the Process flow section you can see how teams are interacting with each other. It shows a live view of how work is moving through the system. If a work item is dependent on multiple teams, it will be blocked by the downstream team until all upstream teams have completed their work. There you also see the current simulation time, which is measured in days.

The Lead time and processing ratio chart shows the lead time of each work item on the horizontal axis, and the processing ratio (processing time divided by lead time) on the vertical axis. The size of each bubble represents how many work items are represented by that point. The chart is updated in real-time as the simulation runs.

Click Start simulation to see how work flows through the system.

Enjoy!
