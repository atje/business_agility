The purpose of this simulation is to demonstrate how changes in process assumptions can impact overall performance of the system. No information is collected, everything is running solely in your local browser.

You start by configuring the organization through the Teams and handoffs section. You can add teams, set their capacity, and define how work is handed off between them. You can configure the simulation parameters in the Parameters section. Hover over the parameter fields to see a description of what they mean.

In the Process flow section you can see how teams are interacting with each other and a live view of how work is moving through the system. If a Feature dependent on multiple teams, it will be blocked until all teams have completed their work. There you also see the current simulation time, which is measured in days

The Lead time and processing ratio chart shows the lead time of each feature on the horizontal axis, and the processing ratio (processing time divided by lead time) on the vertical axis. The size of each bubble represents how many features are represented by that point. The chart is updated in real-time as the simulation runs.

Finally, click Start simulation to see how work flows through the system.

Enjoy!
